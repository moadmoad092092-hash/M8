SHADOW X — موقع أدوات محلي

التشغيل من الهاتف:
1) فك ضغط shadow-x.zip.
2) افتح index.html باستخدام متصفحك أو محرر HTML يدعم المعاينة.
3) لا يحتاج الموقع إلى API أو حساب أو اشتراك.

الملفات:
- index.html: بنية الموقع
- style.css: التصميم المتجاوب الأسود والأخضر
- script.js: التفاعلات والأدوات

ملاحظات:
- ماسح الأكواد فحص نصي مبدئي فقط؛ لا يشغّل الأكواد ولا يضمن خلوها من الأخطاء.
- المحطة السوداء محاكاة تعليمية ولا تنفذ أوامر نظام حقيقية.
- الخط الخارجي اختياري؛ إذا لم يتوفر الإنترنت سيستخدم المتصفح الخطوط البديلة.
